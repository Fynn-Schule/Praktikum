1. Mobile Anwendung (App-APK)
Die App steht als vorkompilierte APK-Datei zur Verfügung.
  
  -Vorgehensweise: Laden Sie die .apk-Datei auf Ihr Endgerät herunter und führen Sie die Installation durch. Sollte die Datei komprimiert sein, extrahieren Sie diese vorab.

  -Systemanforderungen & Kompatibilität: Die Anwendung wurde primär für Android-Betriebssysteme entwickelt.

Hinweis: Die aktuelle Version wurde explizit auf einem Google Pixel 7a getestet. Bei anderen Modellen oder Betriebssystem-Versionen kann die Stabilität nicht garantiert werden.

2. Quellcode (App-Source)
Für Entwicklungszwecke oder zur Einsicht in die Funktionsweise finden Sie im Verzeichnis App-Source sämtliche Quelldateien, die in der finalen APK enthalten sind. Dies dient der Transparenz und ermöglicht spätere Modifikationen am Projekt.

3. Lebenslaufgenerator
Dieses Tool ermöglicht die automatisierte Erstellung von Lebensläufen. Hierfür stehen zwei Anwendungsszenarien zur Verfügung:

  -Option A: Direkte Nutzung der Datei Navigieren Sie zum entsprechenden Ordner im Repository.

  -Laden Sie die Datei herunter und öffnen Sie diese direkt in einem gängigen Webbrowser.

  -Option B: Manuelle Implementierung (Quellcode-Transfer) Falls Sie die Anwendung in eine bestehende Umgebung integrieren möchten:

  -Öffnen Sie die Quellcode-Datei im Repository und kopieren Sie den gesamten Code.

  -Fügen Sie den Code in einen Texteditor Ihrer Wahl ein (z. B. VS Code, Notepad++ oder den Standard-Editor).

  -Speichern Sie die Datei unter dem Namen index.html (oder einem beliebigen Namen mit der Endung .html) ab.

  -Starten Sie die Datei per Doppelklick über Ihren Browser.
